# kotlin-basic-projects

Projetos de treino em Kotlin + Jetpack Compose, em ordem crescente de dificuldade.

## Estrutura

```
kotlin-basic-projects/
├── docs/
│   ├── PROGRESSO.md          roadmap, onde parei, pendências e log
│   ├── TEORIA.md             teoria de cada tópico (com blocos 📝 Caderno)
│   └── gerar_teoria_pdf.py   gera ~/Desktop/kotlin-estudos-teoria.pdf
└── TemperatureConverter/     Projeto 1
```

Cada projeto é um projeto Android independente: abrir **a pasta do projeto** (não a raiz) no Android Studio.
